📌 Overview

MealMatrix is an end-to-end analytics project built on food delivery transaction data. It covers the full workflow, from raw data to a decision-ready dashboard:

text
Raw Data → Validation & Cleaning → EDA → SQL Analysis → KPIs → Power BI Dashboard → Insights → Decisions

The goal is not just to chart the data, but to answer the questions a delivery business actually asks.

🎯 Business Questions
Area	Question
Revenue	Which cuisines, restaurants and cities generate the most revenue? How does it trend over time?
Customers	Who are the repeat customers? What does a high-value customer look like?
Operations	Where and when does delivery take longest? What drives late orders?
Demand	What are the peak hours, days and seasons?
Restaurants	Which restaurants combine high volume with strong ratings, and which underperform?

🧹 Data Cleaning

All cleaning is scripted in clean_data.py so results are reproducible. The pipeline:

Standardizes column names (snake_case) and trims whitespace in text fields
Removes exact duplicate rows and duplicate order IDs
Parses dates and coerces numeric fields
Handles missing values (drops rows missing key fields, imputes the rest)
Flags and removes invalid records (negative amounts, impossible delivery times)
Detects outliers using the IQR method
Engineers features: order hour, day of week, weekend flag, delivery time bands
Writes a cleaned CSV plus a text report of every change made
